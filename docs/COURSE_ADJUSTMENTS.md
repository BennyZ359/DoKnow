# 课程调整与证据保留

本轮 P1-3 规则，2026-11-03。课程调整独立于目标基础信息编辑。

## 作用范围

- 已开始包括任何已保存聊天或学习提交、非 learn 阶段、掌握度、练习状态、复习/完成记录或关联笔记。仅打开页面和浏览器草稿不算已开始。
- 已开始单元固定位置、ID、材料、进度、评价、笔记和复习日期；未开始单元占据的槽位可重排，不能跨越固定单元改变其位置。
- 课程重生成按原有目标难度重新生成全部未开始槽位。难度调整选择新难度，只重新生成未开始槽位，保留已有单元的实际材料；目标显示的难度表示后续课程难度。
- 生成保留槽位数，向规划服务提供待替换主题、位置及已保留主题。demo 明确是模板安排，不宣称真实 AI 规划。
- 替换用新 ID。旧单元标记归档，材料与历史保留，可以只读访问；旧页面不能向归档单元写入。浏览器草稿保留在旧 ID 下，不自动转移到新内容。
- 全部单元已开始时不允许重生成或难度调整；不足两个未开始槽位不能重排。相同难度、原顺序和非法 ID/重复 ID 不构成有效调整。

## 预览、确认与版本

先请求服务器生成并保存预览；显示原课程、拟定顺序、保留/替换单元、难度、课程材料及影响范围，再明确确认。关闭预览不改变课程。确认只引用服务器保存的预览，不能提交替换材料。

目标 `version` 继续只保护基础信息编辑。独立 `course_version` 从 1 开始，每次确认加一。预览绑定目标基础版本、课程版本和全部活动单元版本；预览期间有元信息、学习提交或其他课程调整则拒绝应用，重新预览。确认事务以条件 UPDATE 核对版本并取得行锁，不在等待模型时持有写锁。

课程、归档标记、变更记录及幂等回执一次事务保存。预览和确认均支持原操作重试；同一预览不能重复应用。变更历史保存当时公开课程快照和确认时间，练习答案及未答题库不在历史 API 中暴露。删除目标时连同其预览/变更删除，并清除相关回执正文；独立笔记仍保留。

## 验收场景

1. 有学习/聊天/复习证据时调整剩余部分；逐值比较保留单元、评价、笔记、复习时间和原有回执。
2. 重生成、调整难度和重排分别预览、取消、确认；课程版本增长，基础版本不受影响。
3. 预览后学习、编辑、删除或竞争确认；跨应用实例仍只有合法写入成功。
4. 旧页面向归档单元提交被拒绝；原已完成回执可重放；新材料不泄露练习答案。
5. 预览及确认丢响应、重启后恢复；失败事务不留下半套课程或已完成回执。
6. 0004 及更旧库迁移逐值保留历史，模拟 DDL 失败完整回滚；调整后备份恢复到新库。
7. 键盘操作、焦点、手机布局、生成失败及页面同步失败可恢复；完整后端/浏览器回归。

本轮仅使用 demo、模拟模型及独立数据库；正式学习库、付费模型和实际容器不在执行范围。
